# Hosted reviewer guidance

Compatibility entrypoint for callers that previously loaded the domain-shard
manual. The caller owns scope assignment, tools, scheduling, and output format.

Use [shared evidence guidance](../review-calibration.md),
[severity and package calibration](severity-core.md), and
[shared conflict resolutions](conflicts-core.md), then the relevant domain rules.
Supporting cross-domain reads are allowed. Check claims against current source;
do not preserve incorrect advice merely because another reviewer produced it.
Let the caller's output contract determine how to report unresolved questions.
